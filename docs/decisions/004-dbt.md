## Contexte

Le plan (`REIMPLEMENTATION_PLAN.md` §3 P3 et §7), la matrice et la passation
classaient `DBT` en défaut « champs pieds / brasses inversés », à corriger sans
drapeau. La consigne de session reprenait cette prémisse : « D4 DBT corrigé
sans drapeau ». La chaîne observation → documentation → décision impose de
vérifier la prémisse avant de décider.

## Comportement legacy

Code (`mods_b/7264.js:467`) :

```js
fields[1] = (3.28084  * depth).toFixed(1); fields[2] = "f";
fields[3] = depth.toFixed(1);              fields[4] = "M";
fields[5] = (0.546807 * depth).toFixed(1); fields[6] = "F";
```

Captures (`legacy/cap-tcp.log`, `legacy/cap-fixed.log`) :

```
$SDDBT,26.2,f,8.0,M,4.4,F*38     8,0 m = 26,2 ft = 4,4 fm
$SDDBT,33.5,f,10.2,M,5.6,F*03    10,2 m = 33,5 ft = 5,6 fm
```

L'ordre est celui de NMEA 0183 (`pieds,f,mètres,M,brasses,F`) et les
conversions sont justes. L'exemple « legacy » de l'ancienne matrice,
`$SDDBT,0008.0,f,0013.1,F,0008.0,M`, n'apparaît dans **aucune** capture ni dans
le code ; l'exemple « correct » qui l'accompagnait (`…,F,…,f,…,M`) était
lui-même non conforme.

## Options

1. **Appliquer la « correction »** prévue : produirait une phrase non conforme
   et casserait tous les récepteurs actuels.
2. **Conserver l'ordre legacy**, qui est conforme, sans drapeau, et verrouiller
   par un test.
3. Drapeau entre les deux ordres : aucun intérêt, un seul ordre est correct.

## Décision

Option 2. `DBT` conserve l'ordre et les conversions du legacy, **sans
drapeau**. Le « défaut DBT » est retiré de la matrice, du plan et de la liste
des corrections.

Seules évolutions, qui relèvent d'autres lignes de la matrice : profondeur lue
dans l'état SI du noyau (mètres), talker configurable, format décimal à une
décimale inchangé.

## Justification

- L'observation (code + deux captures indépendantes) contredit la prémisse ;
  décider sur la prémisse aurait introduit un défaut réel.
- La consigne « sans drapeau » est respectée : il n'y a qu'un comportement.

## Compatibilité

Octet pour octet identique au legacy pour une même profondeur. Les golden
files `DBT` sont comparables sans normalisation.

## Conséquences

- `REIMPLEMENTATION_PLAN.md` §7 et `11-testing-strategy.md` §4.1 sont mis à
  jour : `DBT` passe de « corrigé » à « non-régression ».
- Le rapport de session signale cet écart entre la consigne et l'observation,
  pour ratification par l'utilisateur.
